# SteadyXR icon

Original application artwork generated for this project with OpenAI image generation on 2026-09-10. The source PNG retains its transparency.

`SteadyXR.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel sizes, converted from the PNG using Pillow. `preview/app.rc` embeds the icon and version information in the Windows executable. The source package includes both files so rebuilding does not require image generation.
