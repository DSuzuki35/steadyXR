# Standalone stabilized preview

Approved scope: a separate gaming-PC application in this repository captures the existing iRacing preview without a game restart and displays a stabilized copy. The default is Windows Graphics Capture with image analysis; direct OpenXR pose capture remains optional. It does not change the headset image. No OBS, encoding or second scene render is required. Deliver in the user's OneDrive Horizon Lock VR directory, preserving existing packages.

Windows x64 / D3D11 is the first supported backend. Default window capture is independent of the game's VR runtime. The optional OpenXR path supports D3D11 stereo and four-view context/foveal configurations; unsupported backends are reported rather than substituted with unrelated tracking. The existing OBS workflow remains available.

The OpenXR layer snapshots color swapchain images before releasing them to the runtime, then pairs the snapshots with the exact submitted projection pose, FOV and subimage at EndFrame. The native preview consumes GPU shared textures and applies rotational smoothing using vrst_core. Foveal views are composited into their context view using their own submitted projection and orientation. Translation/parallax correction is outside this initial scope.

Capture must not block the game on the preview. A single outstanding shared frame provides bounded backpressure; busy frames are dropped. No viewer heartbeat, pause, or minimized preview disables image copying. Capture resources are on the game's adapter, and the viewer selects that adapter. Frames are rate-limited to 60 Hz by default. No claim of exact GPU cost is made until measured on the actual game; a Pause control supports an A/B comparison.

The app has a settings window and a separate clean preview window with F11 fullscreen on its current monitor. Controls include smoothing, crop, mirrored edges, left/right eye, output rate, reset preview, and pause. Only optional OpenXR setup registers this app's own per-user implicit layer; it does not change the active runtime or other layers. Registration is a deliberate user button, not an automatic consequence of delivering or testing. Only this optional path requires restarting the game after setup.

Verification includes the existing regression suites, native Windows window-capture and D3D11 tests, a fake OpenXR runtime validating release ordering and unchanged submission, stereo/quad-view metadata, pause/backpressure behavior, and a demo preview. Live window capture can be checked on an already running simulator without a restart. Real driving smoothness and optional OpenXR/Pimax integration are reported separately from synthetic tests.

The default window mode selects only an actual iRacingSim process automatically, otherwise requires explicit window selection. Track selected HWND and PID across retries to prevent unrelated recycled windows becoming capture sources. Capture the client area, stop on pause/minimize, and use at most three pending private full frames plus their small GPU analysis buffers. Nonblocking readback must not mismatch image and correction. Preserve SDR colors. No restart or runtime setup is necessary for window mode.
