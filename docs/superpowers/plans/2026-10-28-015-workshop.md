# SteadyXR 0.15 Workshop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development. Track checked steps and evidence in the ledger.

**Goal:** Ship the approved native English UI, optional capture/replay crop workshop and pitch stabilization, retaining normal smoothing and the signed 0.14 capture DLL.

**Architecture:** Keep Win32/D3D11. Record consumer-owned source frames with synchronized pose metadata through bounded hardware encoding; replay through the existing renderer with draft options. Pause live consumption while editing. Independent camera, recording and UI modules can be implemented concurrently with explicit file ownership; integration and verification are sequential.

**Tech Stack:** C++17, Win32, D3D11, Media Foundation, DirectInput, CMake/MSVC.

**Spec:** docs/superpowers/specs/2026-10-28-015-ui-cropping-wizard-design.md

## Global Constraints
- UI stays English, including errors and hints.
- Remove Natural Head Movement from standalone operation; retain ordinary smoothing and gaze.
- Never modify capture sources, IPC layout, rebuild or replace the signed capture DLL.
- Pinned SHA256: 74a6943f014d85b81f301da852b61d5a8cb2251a199130978bf4cbdba097d91d.
- Optional recording, default 30 seconds/30 FPS/2048 longest edge; bounded queues, no silent software encoding fallback.
- No live/replay parallel pipeline while editing; no replay sent to the external live window.
- Existing advanced settings remain accessible. New UI and workshop are native, no WebView.

## Review Focus
- Old profiles enabling Natural must not reactivate it (task 1/3 regression).
- Device loss, disconnect and format/reference changes during a clip stop clearly (task 2).
- Invalid clips or metadata cannot allocate unbounded memory or mismatch images/poses (task 2).
- Crop manipulation at borders preserves aspect, bounds and parameter roundtrip (task 1/3).
- Enter/leave replay, cancellation and seeking cannot leak draft settings or stale history into live (task 4).
