Horizon Lock VR - Version 0.4.1

GAMING PC - STANDALONE PREVIEW
Run Gaming-PC\Start-Preview.cmd after closing the previous preview app.
Existing settings are copied if the new version has no preview.ini.
A working 0.4.0 OpenXR layer is compatible. No reinstall or iRacing restart
is needed for this viewer update. Keep Preview-0.4.0 while its layer is registered.

New: four crop sliders, aspect ratio, configurable render resolution
(default 3840x2160), horizon lock, mirror limit, automatic fullscreen and
monitor selection. The app is in English. See Gaming-PC\Preview-Guide.md.
The HDMI signal resolution still follows Windows display settings.
Disable the old OBS stabilizer on this already stabilized source.

GAMING PC - EXISTING SENDER WORKFLOW
Gaming-PC\Start-Tracking.cmd starts tracking.
Gaming-PC\Start-Delay-Check.cmd starts tracking and the photo timing overlay.
Start SteamVR and the headset first. Run only one sender.
Keep its console open. Ctrl+C stops it.
