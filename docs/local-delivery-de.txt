SteadyXR - Version 0.14.0

NEW IN 0.14.0 - D3D12 OPENXR CAPTURE
D3D11 and D3D12 sessions are detected automatically. The GPU capture preserves
submitted image/pose pairing and feeds the existing preview and OBS source.
Busy buffers skip capture instead of making the game wait for the viewer.
The new DLL needs signing and live runtime validation.

FROM 0.13.0 - SYMMETRIC RENDER EXTENSION
Framing > Render & edge settings > Symmetric (both eyes) links the inner and
outer render margins across eyes. Enabling it copies the selected eye to the
other eye. Both eyes inward: 10% enables the lock too. Save, then restart the
game. Settings and complete presets retain the checkbox. Use it for LMU:
LMU requires matching recommended render dimensions for both eyes.

FROM 0.13.1 - PERMANENT BUILDS AND VECTORXR COMPATIBILITY
The app, OBS source and newly compiled capture DLL have no expiry.
Install/Upgrade connection now registers SteadyXR system-wide, asks for
Windows administrator approval, and disables older per-user registrations.
With VectorXR present, SteadyXR captures before its D3D11-to-D3D12 bridge.
A startup fix avoids an unsafe pre-initialization eye-gaze query in VectorXR.
Only original game frames are captured, not generated intermediate frames.

The new capture DLL MUST be signed again before testing LMU/EAC.
The previous signed 0.13.0/0.12.0 DLL and packages are untouched.
Hardware compatibility is pending validation after signing.
See docs/release-0.14.0-validation.md in the complete package/source.

FROM 0.12.0 - OPTIONAL VIEWER DIRECTOR
Spectator & effects > Director adds lookahead, automatic crop and speed framing.
Speed telemetry supports iRacing and Le Mans Ultimate on the local game PC.
All three start off. Lookahead uses up to four delayed frames and 256 MiB of
texture storage; actual delay and memory use appear in status. Add the video
delay to OBS audio sync. Automatic crop and speed framing need no extra GPU pass.
Lookahead needs OpenXR; window capture supports auto crop and speed framing.
See Viewer-Director-Guide.md and Telemetry-Guide.md. Live driving validation is pending.

NEW IN 0.10.1 - CLEARER NATIVE UI
Capture / Camera / Framing / Output tabs organize the main controls.
Spectator & effects stays visible and opens Gaze & chat / Motion / Exposure /
Bloom / Color pages. Every enhancement remains optional. Values apply when
leaving a field. No new continuous UI rendering or GPU effect is added.
The IPC 4 format remains compatible. Upgrade the capture connection for the
new startup fix and permanent capture build.


NEW IN 0.10.0 - OPTIONAL SPECTATOR CAMERA AND VISUAL EFFECTS
All new features start off. Open Spectator & effects for gaze framing,
chat exclusion, natural head movement and local exposure/bloom/color.
Learn chat position (Ctrl+Alt+C) starts a three-second countdown, followed by
one second of stable gaze. Relearn after recentering, eye/source/session changes
or moving chat. Looking at chat ignores gaze framing while head following continues.
For minimum gaming-PC load, keep local visual effects off and add the new
SteadyXR Visual Effects filter to the capture-card source in stream-PC OBS.
Image-effects A/B compares identical camera framing. No DLSS feature is enabled.
See Spectator-Guide.md for tuning, synthetic measurements and hardware limits.
Pre-0.10 connections: Install/Upgrade connection and restart the game for IPC 4.
Delivery does not change the current connection or launch/restart applications.

SINGLE-PC OBS - DIRECT OPENXR SOURCE
Close OBS, then extract SteadyXR-0.14.0-OBS-Windows-x64.zip. Copy obs-plugins
and data directly into C:\Program Files\obs-studio on the gaming PC.
The same drop-in folders are under Stream-PC. The standalone community ZIP
contains no OBS binaries.
Restart OBS and add the source
"SteadyXR OpenXR Capture". Close the standalone SteadyXR preview; the source
captures and stabilizes directly and does not need a visible preview window.
Use the source's settings import to select Gaming-PC\SteadyXR-0.14.0\SteadyXR.ini.
OBS stores its own settings in the scene collection; the INI stays unchanged.
Reuse this existing source in other scenes instead of creating another capture.
The working SteadyXR OpenXR connection must remain enabled. Existing render
extension settings still apply. OBS and the OpenXR game must use the same GPU.
Updating from pre-0.10 requires Upgrade connection and a game restart.
If no frames arrive, the source shows a black waiting screen. It pauses capture
when hidden. The new build has no expiry.
Game audio remains a separate OBS audio source, as before.

GAMING PC - STANDALONE PREVIEW
Run Gaming-PC\Start-Preview.cmd after closing the previous preview app.
The app is in Gaming-PC\SteadyXR-0.14.0: SteadyXR.exe and SteadyXR.ini.
Your current settings are copied unchanged if SteadyXR.ini is missing.
For a pre-0.10 connection, click Capture > Upgrade connection in the new app,
then restart iRacing. 0.10.x and 0.11.0 share the same capture format.
Keep previous Preview folders while their compatible OpenXR layer is registered. The new DLL is named SteadyXR-OpenXR.dll; the previous connection must be upgraded for 0.10.
For first setup or a pre-0.6 layer: select OpenXR pose capture, click
Upgrade connection (or Install connection), then restart iRacing once.
Delivery does not change your registration or runtime automatically.
Window capture still needs no game restart or connection.

FROM 0.9.0 - SELECTABLE OPENXR OVERLAYS
Overlay layers... in the app and OpenXR overlay layers in OBS provide None,
All supported and individual checkboxes for detected composition layers.
Individual choices apply only to the current game session. After a restart,
select them again. All/None preferences persist. Refresh the list explicitly.
Quad, cylinder and color projection overlays follow the stabilized image.
See openxr-overlays.md for injector order and supported format limits.

FROM 0.8.0 - RESET HORIZON, COMPARISON AND HOTKEYS
Hold the headset approximately upright, then press Reset horizon to refresh
the preview's upright reference. Smoothing is retained. It does not recenter the HMD.
A/B shows the selected comparison for twenty seconds: Original, 50/50 split
(left stabilized, right original), or two complete views side by side.
The same framing is retained and both views keep their aspect ratio. Press again to return immediately. The comparison is temporary and
never becomes part of your saved settings or presets.
Capture/FPS/comparison status stays in the controls, off the live image.
The standalone status is live. In OBS, reopen properties or use Refresh status
to update the status snapshot without disturbing active sliders.

Standalone defaults: Ctrl+Alt+R resets the horizon; Ctrl+Alt+P pauses/resumes;
Ctrl+Alt+N loads the next preset; Ctrl+Alt+B starts/ends the selected A/B comparison.
Hotkeys / A/B... offers Ctrl+Alt, Ctrl+Alt+Shift or Off and reports conflicts.
It also selects the comparison view, which is saved with complete presets.
Next preset cycles Natural, Stream Comfort, Strong Leveling, then saved names.
In OBS, assign your own bindings under Settings > Hotkeys for the SteadyXR
source. Reset, pause, comparison, built-in tuning and three saved INI preset
slots have native OBS actions. Loading a preset does not modify its file.
See OBS-OpenXR-Guide.md and Gaming-PC\Preview-Guide.md for details.

OPENXR LAYERS - INTRODUCED IN 0.7.0
Horizon Lock VR is now SteadyXR. Your settings and presets are retained.
Open OpenXR layers... in the preview or Gaming-PC\Start-Layer-Editor.cmd.
Inspect installed 64/32-bit layers, status, runtime and file paths.
Enable/disable, remove a registration, or move implicit layers within their
registry group. Changes are staged until Apply changes; plugin files stay put.
Apply creates a verified backup in Gaming-PC\Layer-Backups. Undo last apply
and Restore backup... are available. Restart the OpenXR game after changes.
Administrator editor... is required for system-wide edits; the preview stays
unelevated. Opening the editor changes nothing. Register SteadyXR is available
if its registration is absent. The legacy technical layer name is retained.
Configured status does not prove what an already-running game loaded.

Presets... includes Natural, Stream Comfort, Strong Leveling and your own
complete presets. Save new, Load, Overwrite selected and Delete are available.
User presets live in Gaming-PC\Presets and survive version upgrades.
All settings are included, including both eyes and pending render drafts.
Slider repaint is fixed. Y offset now uses the hidden stabilization reserve.
Render / edges still offers per-eye extra OpenXR scenery, Both eyes inward,
asymmetric stabilization reserves and vertical framing adjustment.
The original captured pixels stay available behind the crop for stabilization.
Extra rendering is off by default. Save render settings, then restart the game;
edge reserves and Y offset work immediately. GPU cost depends on your setup.
Designed for native OpenXR and SteamVR OpenXR with SBoys3; both still need
physical validation. See Gaming-PC\Preview-Guide.md for details.
Default output is 3840x2160. The app is in English.
The HDMI signal resolution still follows Windows display settings.
Disable the old OBS stabilizer on this already stabilized source.
